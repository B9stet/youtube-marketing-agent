# POC-07 통합 검증

- 상태: 검증 완료 (2026-11-23)
- 우선순위: 필수
- 선행 과제: POC-01 입력 시험, POC-02~06
- 실제 게시: 이 과제에서 사용자의 게시 동작으로 한 건 수행

## 목적

앞선 검증을 하나로 연결해 두 영상의 맥락에 맞는 초안과 한 영상의 실제 게시를 확인하고, PoC의 다음 단계 진행 여부를 판정한다.

## 주요 요구사항

- 영상 2개의 실제 자료로 각각 고민 한 줄과 서로 다른 댓글 초안을 만든다.
- 사용자 확인을 거친 댓글 한 건을 한국어 유튜브 화면에서 순차 입력하고 실제 게시 및 내 댓글 확인까지 수행한다.
- 게시 전에 영상 중복과 일일 한도를 검사하고, 진행 상태와 결과를 기록한다.
- 게시와 내 댓글 확인 후 방금 작성한 댓글을 삭제하고 결과를 기록한다.
- 자막, 댓글 품질, 실패 캡처와 운영 제한의 개별 검증 결과를 통합 판정에 포함한다.

## 주요 제약사항

- 실제 게시 대상은 중복 검사를 통과해야 하며, 한도 검증을 위해 대량의 실제 댓글을 게시하지 않는다.
- 데이터 조회와 AI 생성, 실제 유튜브 게시의 성공 여부를 모의 응답만으로 판정하지 않는다.
- 최초 로그인, 사용자의 댓글 확인과 게시 시작이 가능한 로컬 환경을 준비한다.
- 최종 과제의 시연 영상은 2~3분이므로 PoC에서 전체 흐름의 소요 시간을 기록한다.

## 기술 후보

| 후보 | 적용 방식과 고려할 점 |
| --- | --- |
| **pytest + 임시 SQLite DB** | 중복, 일일 한도, 날짜 변경 및 오류 상황을 격리된 데이터로 검증한다. 실제 API와 실제 게시 검증은 별도 실험으로 남긴다. |
| **Playwright + 실제 Chrome** | 로그인된 전용 프로필에서 순차 입력, 게시와 화면 확인을 검증한다. 실제 댓글 게시는 통합 시험에서 한 건 수행한다. |
| **OBS Studio 또는 Windows 화면 녹화** | PoC 진행 화면과 최종 시연을 기록하는 후보이다. 대시보드와 크롬 화면이 모두 보이도록 녹화 구성을 확인한다. |

권장 출발점은 **pytest로 제한과 오류를 검증하고, 실제 Chrome에서 한 건을 별도로 통합 검증**하는 구성이다.

참고: [pytest 임시 디렉터리](https://docs.pytest.org/en/stable/how-to/tmp_path.html), [OBS 화면 캡처](https://obsproject.com/kb/window-capture-sources)

## 사전 준비

- 로그인된 전용 Chrome 프로필 1개를 준비한다.
- 최근 연애 관련 영상 2개를 선정한다. 두 영상은 각각 확인 가능한 자막 또는 스크립트와 인기 댓글이 있어야 한다.
- 실제 댓글을 달 영상 한 개의 댓글 사용 가능 여부와 기존 게시 기록을 확인한다.
- yt-dlp, Node.js와 10100번 AI 연결을 준비한다.
- 실제 게시 전에 POC-05의 제한 검사와 POC-06의 기록을 연결한다.
- 테스트 결과와 화면 캡처를 로컬에 저장할 위치를 준비한다.

## 통합 검증 절차

1. 최신 영상 목록을 불러오고 영상 A와 B의 썸네일, 제목, 채널, 날짜를 확인한다.
2. 영상 A와 B를 각각 선택해 자료의 출처, 구체적인 영상 근거, 고민 한 줄, 댓글 초안을 확인한다.
3. 두 초안을 POC-04의 품질 조건과 비교하고 영상 내용이 서로 다르게 반영됐는지 평가한다.
4. 영상 하나의 최종 댓글을 확인하거나 수정하고, 영상 중복과 하루 상한 검사를 실행한다.
5. 사용자가 게시를 시작하면 전용 크롬 프로필을 열어 한 글자씩 입력하고 실제 게시한다.
6. 해당 계정 화면에서 내 댓글을 확인한 뒤 해당 댓글을 삭제하고 기록과 진행 상태를 확인한다.
7. POC-05의 가상 기록 시험과 POC-06의 실패 캡처 시험 결과를 함께 확인한다.

실제 게시 한 건은 POC-01의 게시 확인 결과로도 사용한다. 중복 방지 시험을 위해 같은 영상에 다시 게시하지 않는다.

## 통과 조건

- [x] 최신 검색 결과에서 서로 다른 유효한 영상 2개를 선택할 수 있다.
- [x] 두 영상에서 실제 근거가 확인되는 서로 다른 고민과 초안이 나오고 POC-04 품질 조건을 모두 충족한다.
- [x] 영상 한 개에서 한국어 크롬 화면의 순차 입력, 실제 게시, 해당 계정의 내 댓글 확인이 성공한다.
- [x] 게시 확인 후 방금 작성한 댓글이 삭제된 것을 확인한다.
- [x] POC-05의 중복, 상한, 날짜 변경, 불확실한 게시 결과 시험이 통과한다.
- [x] POC-06의 진행 상태, 게시 이력, 실패 사유와 화면 캡처 시험이 통과한다.
- [x] 전체 흐름의 소요 시간을 기록해 최종 2~3분 시연 영상에 담을 수 있는지 판단한다.

## 결과 기록

각 과제의 통과 또는 실패, 실행 환경, 시험 일시, 영상 ID, 자료 출처, 생성 결과, 확인 방법, 오류와 다음 조치를 남긴다. 실제 게시 화면 녹화와 캡처는 로컬 결과물로 보관한다.

필수 조건이 실패하면 해당 원인을 해결한 뒤 다시 검증한다. 원문 과제의 최종 제출을 위한 2~3분 시연 영상과 제작 의도 작성은 PoC 검증 결과를 바탕으로 별도로 진행한다.
