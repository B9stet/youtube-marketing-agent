# POC-02 연애 영상 불러오기

- 상태: 검증 완료 (2026-11-23)
- 우선순위: 필수
- 선행 조건: yt-dlp와 Node.js 실행 환경
- 후속 과제: POC-03, POC-04, POC-07

## 목적

연애 관련 최신 영상을 검색해 사용자가 영상을 구분하고 선택하는 데 필요한 정보를 확보한다.

## 주요 요구사항

- 기본 검색어를 연애로 설정하고, 최신순으로 영상 검색을 요청한다.
- 각 결과에서 영상 ID, 썸네일, 제목, 채널명, 게시 날짜를 확보한다.
- 목록에서 영상을 선택하거나 PoC 실행 시 영상 ID를 지정할 수 있어야 한다.
- 같은 영상의 여러 주소 형식은 동일한 영상 ID로 식별한다.
- 검색 실패, 할당량 오류, 빈 결과, 사용할 수 없는 영상을 구분해 표시하거나 기록한다.
- 링크 직접 입력은 최종 과제의 가점 항목이며 본 PoC의 필수 통과 조건은 아니다.

## 주요 제약사항

- 최신순은 검색 결과의 정렬 기준이다. 유튜브 검색 색인 반영 시간에 따라 방금 게시된 영상이 즉시 검색되지 않을 수 있다.
- YouTube Data API를 사용하려면 API 키와 사용 가능한 할당량이 필요하다.
- 최소 2개 영상의 썸네일, 제목, 채널명, 날짜와 영상 ID를 후속 과제에 전달해야 한다.
- 검색 결과가 없거나 요청이 실패했을 때는 오류나 빈 결과로 표시한다.

## 기술 후보

| 후보 | 적용 방식과 고려할 점 |
| --- | --- |
| **yt-dlp** | 유튜브 검색 결과와 각 영상의 메타데이터를 가져온다. PoC에서는 이 방식을 사용해 검색과 날짜순 표시를 확인했다. |
| **YouTube Data API + google-api-python-client** | 공식 검색 API에서 영상 결과를 최신순으로 조회한다. Python 클라이언트와 API 키 설정이 필요하다. |
| **YouTube Data API + HTTP 클라이언트** | 같은 공식 API를 requests 또는 httpx로 호출한다. 필요한 응답 처리와 오류 처리를 직접 작성한다. |
| **Playwright로 유튜브 검색 화면 읽기** | API를 대체할 수 있는 비교 후보이다. 화면 구조와 표시 상태에 의존하므로 변화에 대한 유지보수가 필요하다. |

PoC에서는 **yt-dlp**를 사용했다. YouTube Data API는 별도 API 키가 있을 때 사용할 수 있는 대안이다.

## 검증 절차

1. 연애 키워드로 검색하고 요청한 최신순 정렬이 결과에 반영되는지 확인한다.
2. 유효한 영상 두 개의 썸네일, 제목, 채널명, 게시 날짜를 실제 영상과 대조한다.
3. 두 영상의 ID를 POC-03에 전달한다.
4. 검색 실패 또는 빈 결과를 재현해 사용자에게 결과를 알리는지 확인한다.

## 통과 조건

- [x] 서로 다른 유효한 영상이 두 개 이상 조회된다.
- [x] 두 영상 모두 썸네일, 제목, 채널명, 게시 날짜와 영상 ID를 확인할 수 있다.
- [x] 선택한 영상의 ID가 이후 맥락 수집 단계로 정확히 전달된다.
- [x] 검색에 실패하거나 결과가 없을 때 정상 결과인 것처럼 표시하지 않는다.

## 확인할 자료

검색 시각과 조건, 조회 결과 두 건의 필수 정보, 선택된 영상 ID, 오류 처리 결과.
