# PoC 검증 기록

검증일: 2026-11-23, 한국 시간. 실행 환경: Windows, Google Chrome, 로컬 10100번 AI 연결.

## 과제별 결과

| 과제 | 결과와 근거 |
| --- | --- |
| POC-01 | 일반 Chrome에서 전용 프로필을 로그인한 뒤 자동화 창에서 로그인 유지 확인. 한글 순차 입력, 실제 게시, 내 댓글 확인 및 삭제를 실제 유튜브에서 검증. |
| POC-02 | 연애 검색으로 실제 영상 8개와 각 영상의 제목, 채널, 날짜, 썸네일을 표시. |
| POC-03 | 영상 C2LVY7NZeFU와 JqW9PxxvuAA에서 한국어 자막과 각각 인기 댓글 10개 확보. 자막 없음과 수집 오류를 별도 시험. |
| POC-04 | 두 영상에서 각각 실제 발언에 근거한 서로 다른 공감 댓글 생성. 사용자 요청에 따라 이번 초안과 실제 시험 댓글에는 운명원과 사주를 넣지 않음. |
| POC-05 | 영상 ID 정규화, 서로 다른 프로필 간 중복 차단, 10건 상한, 동시 요청, 자정, 재시작과 게시 불명 상태를 자동 시험. 삭제한 댓글도 한도와 중복 기록에 유지. |
| POC-06 | 진행 단계와 시간순 이력 확인. 게시 전 실패를 재현해 실패 사유와 화면 캡처를 확인. |
| POC-07 | 대시보드에서 실제 게시와 삭제까지 검증. 수정 후 두 번째 영상에서는 순차 입력, 게시 확인, 자동 삭제가 한 흐름으로 성공. |

## 실제 게시와 삭제

- 첫 영상: C2LVY7NZeFU. 게시를 확인했으나 유튜브 삭제 메뉴 형태가 예상과 달라 자동 삭제가 실패했다. 메뉴 선택 방식을 수정하고 같은 계정과 댓글을 재확인해 삭제했다.
- 두 번째 영상: JqW9PxxvuAA. 게시 후 해당 계정과 댓글을 확인하고 자동 삭제했다. 유튜브 화면의 삭제 완료 메시지도 확인했다.
- 현재 로컬 기록: 게시 확인 및 삭제 2건, 하루 사용량 2/10건. 게시 전 실패 한 건은 한도에서 제외된다.
- 테스트 댓글은 모두 영상에 대한 공감 내용만 사용했다. 운명원 문구는 선택적으로 댓글 맨 끝에 추가하는 기능으로 분리했다.

## 시간과 증거

- 검색과 저장된 초안 표시: 23.1초.
- 다른 영상의 자막과 인기 댓글을 읽고 새 공감 초안 생성: 26.7초.
- 수정 후 실제 게시 예약부터 삭제 확인까지: 32초. 위 시간은 각각 별도 실행에서 측정했다.
- 실제 두 번째 게시와 삭제 녹화: 로컬 output/poc-evidence/02-typing-post-delete.webm, 약 33초.
- 게시 확인 및 삭제 확인 화면: 로컬 output/poc-evidence/02-post-confirmed.png, 02-deleted.png.
- 자동 시험: 프로젝트의 .venv 환경에서 pytest 22건 통과.

녹화와 화면 캡처, 로그인 프로필, 작업 이력은 로컬에 보관하며 Git에 포함하지 않는다. 과제 제출을 위한 2~3분 시연 영상은 별도로 구성한다.
