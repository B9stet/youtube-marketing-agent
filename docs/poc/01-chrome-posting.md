# POC-01 크롬 프로필과 댓글 게시

- 상태: 검증 완료 (2026-11-23)
- 우선순위: 필수
- 선행 조건: Windows, Chrome, 유튜브 계정 1개
- 최종 실제 게시 검증: POC-05와 POC-06을 연결한 뒤 POC-07에서 수행

## 목적

자동화 전용 크롬 프로필을 열고 한국어 유튜브 화면에서 댓글을 한 글자씩 입력해 실제 게시와 내 댓글 확인까지 할 수 있는지 검증한다.

## 주요 요구사항

- 평소 사용하는 기본 프로필과 구분되는 전용 사용자 데이터 폴더로 실제 Chrome을 연다.
- 사용자는 최초에 해당 프로필에서 직접 구글 계정에 로그인한다. 비밀번호를 프로그램에 저장하거나 수집하지 않는다.
- 브라우저를 닫았다가 다시 열었을 때 같은 프로필의 로그인 상태와 사용할 계정을 확인할 수 있어야 한다.
- 선택한 실제 영상으로 이동하고, 한국어 화면에서 댓글 입력 영역과 게시 버튼을 찾는다.
- 40~120자의 한글 댓글이 화면에 한 글자씩 나타나도록 입력한다. 한 번에 붙여넣거나 입력란을 완성된 문자열로 교체하는 방식은 통과로 보지 않는다.
- 게시 전에 실제 입력된 내용이 확정한 초안과 일치하는지 확인한다.
- 사용자가 게시를 시작한 경우에만 게시 버튼을 누르고, 게시 후 화면에서 해당 계정의 댓글 내용을 확인한다.
- 게시 확인 후에는 작성한 계정과 내용이 정확히 일치하는 댓글만 삭제하고 삭제 여부를 기록한다.
- 로그인 문제, 댓글 사용 중지, 화면 요소 탐색 실패, 게시 결과 미확인 등을 구분해 POC-06에 전달한다.

## 주요 제약사항

- 실행 환경은 Windows의 로컬 Chrome과 한국어 유튜브 화면이다. PoC 필수 범위는 로그인된 프로필 1개다.
- 자동화 전용 프로필은 평소 쓰는 기본 프로필과 분리한다. 같은 사용자 데이터 폴더를 여러 브라우저 인스턴스가 동시에 사용하지 않게 한다.
- 계정 로그인은 사용자가 직접 처리하며, 재인증이 필요한 경우 진행을 멈추고 상태를 알린다.
- 한글 입력은 실제 화면에서 글자가 순차적으로 나타나는지 검증한다. 자동화 도구의 비영문 문자 입력 이벤트는 영문 키 입력과 다를 수 있다.
- 실제 게시 시험은 POC-05와 POC-06을 연결한 뒤 POC-07의 한 건으로 수행한다.

## 기술 후보

| 후보 | 적용 방식과 고려할 점 |
| --- | --- |
| **Python + Playwright + Chrome** | 전용 사용자 데이터 폴더로 영구 컨텍스트를 열고, 화면 요소 탐색과 단계별 대기를 구현한다. 글자별 한글 입력과 로그인 유지 여부는 실제 환경에서 검증해야 한다. |
| **Python + Selenium + ChromeDriver** | ChromeOptions의 사용자 데이터 폴더를 지정해 같은 흐름을 구현할 수 있다. ChromeDriver와 화면 요소 대기 방식을 함께 관리해야 한다. |

권장 출발점은 **Playwright**다. 화면 캡처와 브라우저 제어를 POC-06에서도 재사용할 수 있다.

참고: [Playwright 키보드 입력](https://playwright.dev/python/docs/api/class-keyboard), [ChromeDriver 사용자 프로필](https://developer.chrome.com/docs/chromedriver/capabilities/)

## 검증 절차

1. 전용 프로필을 열어 수동으로 로그인하고, 닫은 뒤 같은 프로필을 다시 연다.
2. 댓글 입력이 가능한 영상을 열고 미리 준비한 한글 문장을 입력한다. 이 단계에서는 게시하지 않는다.
3. 입력 과정의 화면을 기록하고 초안과 실제 입력값을 대조한다.
4. POC-05와 POC-06을 연결한 후, POC-07의 실제 게시 한 건으로 게시와 내 댓글 확인을 검증한다.

## 통과 조건

- [x] 프로그램 재시작 후에도 전용 프로필에서 사용할 계정을 확인할 수 있다.
- [x] 40~120자 한글 문장이 눈으로 확인할 수 있는 속도로 순차 입력되고 문자가 손상되지 않는다.
- [x] 중복 및 상한 검사를 통과한 실제 댓글 한 건을 게시하고, 해당 계정 화면에서 동일한 내용을 확인한다.
- [x] 방금 작성한 댓글을 삭제한 뒤 화면에서 제거된 것을 확인한다.
- [x] 실패 시 현재 단계와 이유를 기록하고 화면 캡처를 남긴다.

## 확인할 자료

입력 과정 화면, 사용 프로필 식별명, 게시 영상 ID, 게시 전후 상태와 내 댓글 확인 화면. 계정 비밀번호와 쿠키는 결과 자료에 포함하지 않는다.

참고: [Playwright 영구 프로필 문서](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context)
