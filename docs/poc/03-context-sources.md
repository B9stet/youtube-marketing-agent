# POC-03 영상 맥락과 근거 확보

- 상태: 검증 완료 (2026-11-23)
- 우선순위: 필수
- 선행 과제: POC-02에서 선택한 영상 2개
- 후속 과제: POC-04

## 목적

영상이 다루는 고민과 구체적인 말 또는 장면을 파악할 수 있도록 자막, 영상 정보, 인기 댓글을 확보하고 출처를 구분한다.

## 주요 요구사항

- 자막 또는 스크립트를 볼 수 있는 영상 2개를 대상으로 실제 텍스트 확보 방법을 검증한다.
- 영상 제목, 설명, 인기 댓글을 함께 확보해 AI 입력에 제공한다. 인기 댓글은 YouTube Data API의 관련성 순 정렬 등을 이용해 수집하고, 사용한 기준을 기록한다.
- 각 근거가 자막, 제목, 설명, 댓글 중 어디에서 왔는지 구분한다. 자막에 시간 정보가 있으면 함께 보존한다.
- 자막이 없는 영상은 제목과 설명을 대체 자료로 사용하고, 인기 댓글을 함께 읽는다.
- 영상에 자막이 없다는 사실과 자막이 있지만 가져오는 데 실패한 오류를 구분한다.
- 영상 속 실제 말이나 장면을 뒷받침할 자료가 부족하면 그 상태를 표시한다. 사용자가 영상을 확인해 근거를 보완할 수 있게 한다.
- 댓글의 내용은 시청자 반응으로 활용하되, 영상 속 실제 발언이나 장면의 근거로 자동 확정하지 않는다.

## 주요 제약사항

- 공식 자막 다운로드 API는 영상 편집 권한이 필요하므로 다른 사람이 올린 영상에 일반적으로 사용할 수 없다.
- 실제로 자막이 없는 경우와 자막은 있지만 수집이 실패한 경우를 구분한다.
- 시청자 댓글은 반응을 파악하는 자료다. 댓글에 등장하는 문장을 영상의 실제 발언으로 간주하지 않는다.
- 영상 속 말이나 장면을 뒷받침하는 자료가 부족하면 임의로 만들어 내지 않고 사용자 확인을 요청한다.
- 인기 댓글의 수집 기준을 기록한다. API의 관련성 순 정렬과 유튜브 화면의 정렬 결과가 항상 같다고 가정하지 않는다.

## 기술 후보

| 후보 | 적용 방식과 고려할 점 |
| --- | --- |
| **yt-dlp** | 한국어 자막과 인기 댓글을 확보한다. PoC에서 실제 영상 두 편으로 검증했다. |
| **youtube-transcript-api** | 공개 영상의 자막과 자동 생성 자막을 읽는 비공식 Python 라이브러리다. 한국어를 우선 언어로 지정하고, 요청 차단 및 영상별 접근 실패를 실제로 시험한다. |
| **Playwright + 유튜브 스크립트 화면** | 유튜브 화면에서 스크립트를 볼 수 있을 때 표시된 텍스트를 확보하는 후보이다. 화면 구조와 스크립트 제공 여부에 의존한다. |
| **YouTube Data API 댓글 조회** | commentThreads.list로 영상 댓글을 조회하고 관련성 순 등의 기준을 명시한다. 댓글이 없거나 사용 중지된 영상의 예외 처리가 필요하다. |
| **YouTube Data API 자막 다운로드** | 직접 편집 권한이 있는 영상의 자막 검증에 활용할 수 있다. 임의의 타인 영상용 기본 수집 방식으로 사용하지 않는다. |

PoC에서는 **yt-dlp**로 자막과 인기 댓글을 확보했다. 자막이 없는 영상은 제목과 설명으로 대체하고, 영상 근거가 부족하면 사용자가 확인한 말을 보완할 수 있다.

참고: [youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api), [댓글 조회 API](https://developers.google.com/youtube/data/reference/rest/v3/commentThreads/list)

## 검증 절차

1. 선택한 두 영상에서 실제 자막 또는 스크립트 내용과 인기 댓글을 수집한다.
2. 각 영상에서 댓글 초안에 반영할 수 있는 구체적인 발언 하나 이상을 고르고 원문과 대조한다.
3. 자막이 없는 영상 또는 자막 조회 결과가 없는 상황을 재현해 제목과 설명 기반 처리를 확인한다.
4. 자막이 있지만 수집이 실패한 상황과, 영상 내용의 근거 자체가 부족한 상황을 각각 재현한다.

## 통과 조건

- [x] 자막을 볼 수 있는 영상 2개에서 각각 실제 발언 하나 이상을 프로그램이 확보한다.
- [x] 두 영상의 인기 댓글을 각각 확보하고 수집 기준을 기록한다.
- [x] 자막이 없는 경우 제목, 설명, 인기 댓글을 AI에 전달할 수 있다.
- [x] 자막 없음, 자막 수집 오류, 영상 근거 부족을 구분해 보여준다.
- [x] 확보된 자료의 출처와 원문을 POC-04에 전달한다.
